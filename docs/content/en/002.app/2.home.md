The **dashboard** is the initial screen: it provides a summary of your data and quick access to the main modules.

## Summary

The **summary** card shows how many **hosts** and **access keys** are enabled and disabled.

## Latest items

The dashboard lists the five most recent hosts and five most recent access keys that have not been deleted, including disabled ones. From each list you can open the full module ([Hosts](/hosts/overview), [Access keys](/passkeys/overview)).

## Keyboard shortcuts

From the dashboard you can open the creation forms directly with the keyboard:

| Shortcut | Action |
| --- | --- |
| `Shift+K` | Create a new access key |
| `Shift+H` | Create a new host |
