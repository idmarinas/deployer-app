This section explains how **:vars{n="project"}** works internally: its components, how data is stored and protected, and how information flows between the frontend and backend. It also covers [soft delete and trash](./trash), which is shared across modules.

## Architecture

:vars{n="project"} is a **desktop application split into two halves** that work together:

- **Frontend (Vue 3 + TypeScript + Nuxt UI v4)** — the entire user interface. Nuxt UI is used **as a library**, not as a meta-framework: the application is built with Vite and there is no additional server.
- **Backend (Rust + Tauri 2)** — native processes the interface cannot handle on its own: SSH/SFTP connections, Stronghold vault management, database initialization and migration execution.

Core pieces:

- **Local database (SQLite)** — all data is stored in a SQLite file on your machine; it never leaves your device.
- **Data access (Drizzle ORM in proxy mode)** — the frontend reads and writes the database through Drizzle. The proxy **transparently encrypts and decrypts** sensitive fields declared as `encryptedText(...)`.
- **Stronghold vault** — stores the AES keys used to encrypt credentials. The frontend is the **only writer** of the vault; the backend only opens it for **reading** when it needs to decrypt SSH credentials.
- **SSH/SFTP orchestration** — the backend establishes SSH/SFTP connections and runs remote commands, connection tests, console sessions, file transfers and task cancellation. Some features, such as metrics, system information or updates, run as saved commands over that connection.

## How the parts work together

```text
┌─────────────────────┐        ┌─────────────────────┐
│  Frontend (Vue)     │  ───►  │  Backend (Rust)     │
│  · UI + Drizzle     │ invoke  │  · SSH/SFTP         │
│  · encrypt/decrypt  │  ◄───  │  · Stronghold (read) │
│  · Stronghold write │        │  · DB/migrations     │
└─────────────────────┘        └─────────────────────┘
        │  Drizzle proxy                │
        ▼                              ▼
   ┌────────────────────────────────────────┐
   │  Local SQLite (encrypted ENC:... data) │
   └────────────────────────────────────────┘
```
