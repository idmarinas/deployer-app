The **Commands** module lets you manage your reusable commands.

## Listing

The table shows the expand button, the **Key** (with an **Internal** badge for seed commands), the **Name**, the **Timeout** and the **Enabled** state. Expanding a row reveals the description, the full command, the parser type and the creation and update dates. You can **Test**, **Edit** and **Delete** each command; **Delete** is disabled for internal commands. The **Deleted** tab lets you restore or permanently delete items.

## Create and edit

From **Add command** you define the command and can test it before saving with **Test**: that test uses the unsaved text. In edit mode, **Test** runs the saved definition, although the preview reflects the form changes; save first if you modified the script or the parameters ([Testing](./testing)). The key is generated on creation and cannot be changed afterwards; the fields and their rules are covered in [Input parameters](./inputs) and [Parsers](./parsers).

## Enable / disable

The **Enabled** toggle in the toolbar activates or deactivates the command. Disabled commands remain in the **Inactive** tab, but cannot be run: pressing **Test** on one fails with a "Command is disabled and cannot be executed" error.
