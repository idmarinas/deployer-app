**Global variables** are values with a readable name and a unique **slug** that can be reused in commands without repeating the value. See [Interpolation](./interpolation) for how to use them.

## What a variable stores

- **Name** — a readable, unique identifier.
- **Slug** — the stable key that identifies the variable in expressions. It is **auto-generated** from the name and **locked** when editing.
- **Description** — optional rich text.
- **Value** — the data substituted when the variable is used.
- **Enabled** — distinguishes variables ready to use from drafts.
- **Secret** — marks the value as sensitive.

## Value and secrets

The value is required when the variable is **enabled** or marked as **secret**; a disabled, non-secret variable can remain a draft with an empty value.

Secret variables are stored **encrypted** with the vault keys (`encryptedText(...)` on the `value` column). Normal reads return the value masked, so it **does not appear in the list**; it is only decrypted when a flow needs it.

::warning
A variable marked as secret **cannot be made public again**. The secret option is locked when editing, and the data layer forces `is_secret = true` if the record was already secret.
::
