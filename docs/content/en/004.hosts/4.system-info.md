The **Host information** tab of a host view lets you inspect the remote operating system details.

## What it shows

- **Distribution** — operating system and version.
- **Kernel** — kernel version.
- **Architecture** — machine platform (x86_64, aarch64, etc.).
- **Package manager** — apt, yum or dnf.
- **CPU** — number of cores.
- **Total memory** — installed RAM.
- **Total disk** — storage capacity.

## How to check it

From that tab, press **Refresh**. The app runs the command stored in the database over SSH —the frontend orchestrates interpolation and the backend runs the remote command— and saves the result against the host. Until you check it, the tab has no data.

## Time between checks

The button becomes available again **one minute** after each check. Once checked, the information stays stored on the host until it is refreshed again; there is no wait time in the backend.

::note
System information is obtained with the `system_info` seed command of :vars{n="project"}.
::
