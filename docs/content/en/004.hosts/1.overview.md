**Hosts** are the SSH machines you manage from :vars{n="project"}. Each host stores its connection details and its state (system information, metrics and package updates).

## Host fields

- **Name** — readable identifier (unique).
- **Description** — optional rich text.
- **Host** — server address: **IPv4** or **IPv6**.
- **Base directory (file manager)** — initial path of the remote panel; it is not the working directory of the console or of deployments ([Browsing files](/file-manager/navigation)).
- **Port** — SSH port (0-65535; **22** by default).
- **Username** — user to connect with.
- **Authentication type** — **password** or **access key**.
- **Password** — required when the authentication type is **Password**. It is stored **encrypted** in the Stronghold vault.
- **Access key** — the passkey to use when the authentication type is **Access key** (see the **Access keys** section of the app).
- **SSH fingerprint** — `SHA256` fingerprint of the server key. It is obtained by testing the connection and must be confirmed; later connections verify it and reject access if it changes.
- **Enabled** — disabled hosts do not appear in the selectors of the console, the **Test command** dialog or the file manager.

## State

The host detail view organizes all its information into three tabs:

- **Host information** — operating system, kernel, architecture, package manager, CPU, RAM and disk ([System information](./system-info)).
- **Updates** — upgradable packages with classification by change type, packaging and security flag ([Updates](./updates)).
- **Host status** — CPU, memory and disk usage as an on-demand snapshot ([Metrics](./metrics)).

## Main actions

- [Test connection](./connection) — check that SSH access works.
- [Manage hosts](./manage) — create, edit, view, delete and enable.
- **Remote console** — run commands on the host ([Remote console](/console/usage)).
