The **Updates** tab of a host view lets you find upgradable packages and apply updates directly from the app.

## Find updates

From that tab, press **Refresh** to search. The app runs the `upgradable_packages` seed command over SSH —the frontend orchestrates interpolation and the backend runs the remote command— and saves the list of available packages.

Each package is **classified automatically** by change type:

- **Patch** (`patch`) — bug fixes.
- **Minor** (`minor`) — compatible new functionality.
- **Major** (`major`) — major change (may break compatibility).
- **Packaging** (`packaging`) — packaging-only change, with no comparable semver version.
- **Unknown** (`unknown`) — the type cannot be determined.

In addition, each package has a **Security** (`is_security`) flag independent of the classification.

## Apply updates

From the package table you can:

- **Update package** — button in the package row.
- **Update selected ({count})** — check several packages and press the button.
- **Update all ({count})** — apply all available updates.

All three actions show a confirmation dialog before running.

The update uses the `update_packages` seed command, editable from the command library, with the script `sudo DEBIAN_FRONTEND=noninteractive apt-get install --only-upgrade -y {{params.packages}}`. The `packages` parameter is required and contains the selected packages. The remote user needs passwordless `sudo`, because the SSH session is not interactive: the **Use sudo** option was removed in 0.4.0, so the command always uses `sudo`. The view does not run `apt-get update`: the index cache must be up to date. It only applies to servers with `apt-get`.

## Time between checks

The **Refresh** button becomes available again **2 minutes** after each search. There is no option to force it earlier; pressing it again once that period has elapsed starts a new check.

::note
Detection and classification use the server's package manager ([System information](./system-info)) and the `upgradable_packages` seed command.
::
