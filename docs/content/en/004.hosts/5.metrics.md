The **Host status** tab (metrics) of a host view shows an on-demand snapshot of the server's resource usage.

## What it shows

- **CPU usage** — CPU usage percentage.
- **RAM usage** — percentage of RAM in use.
- **Disk usage** — percentage of disk space used.

## How to check them

From that tab, press **Refresh**. The app runs the command stored in the database over SSH —the frontend orchestrates interpolation and the backend runs the remote command— and saves the percentages against the host.

## Time between checks

The button becomes available again **1 minute** after each check. Once that period expires, pressing it again runs the SSH command again; there is no 15-minute wait time in the backend.

::note
Metrics are obtained with the `system_metrics` seed command of :vars{n="project"}.
::
