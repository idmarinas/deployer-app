You can copy an access key's **public key** to a host to connect with that key without a password. The application adds it to the remote user's `~/.ssh/authorized_keys` file.

## How it works

From the key **list**, use the copy-to-host action: it is an icon-only button, with no text or tooltip; the detail view does not offer this action. A dialog opens where you must specify:

1. **Host** — the host where you want to copy the key. The selector has a search field, shows each host's status and excludes deleted hosts. The **Only enabled hosts** switch filters out disabled hosts and is off by default; when you change it, the selection is cleared if the host is no longer available.
2. The buttons in the dialog footer:
   - **Copy to host** — adds the public key to the host's authorized keys.
   - **Remove from host** — removes that public key if it was already installed.

The application connects over SSH and runs the necessary commands on `~/.ssh/authorized_keys`: it creates `~/.ssh` with permissions `700`, creates the file with `600` and adds the key line. To remove it, it rewrites the file via `.tmp` with `chmod 600`. The key is compared by **exact line**, without comments, and the operation runs as the user configured on the host.

## Requirements

- The host must have **valid saved credentials** (a password or the access key referenced by the host), because the application needs to connect over SSH: it does not automatically use the access key you are copying. The dialog does not offer fields for temporary credentials.
- A **disabled host can be selected** with the default filter; only deleted hosts are excluded.
- :labels-version{version="0.4" is-new size="sm"} The host must have a **confirmed SSH fingerprint** (`SHA256:<base64>`) that has not changed: if it is missing or does not match, copying or removal is blocked.

## Notes

- **Copying is idempotent**: the `grep -qxF` check prevents duplicating an exactly identical line. Comments or leading spaces are not normalized, so a variant of the same key would be added as another line.
- **Remove from host** removes **all** exactly identical lines and returns an error if the `authorized_keys` file does not exist or if that public key was not installed.
