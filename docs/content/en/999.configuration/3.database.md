The **Database** settings tab shows the state of the SQLite file and lets you restore the application's default data.

## Information

The **Information** subtab shows the file and table data.

- **File** — path, total size, number of tables, number of pages and page size.
- **Application tables** — for each table, rows and size are shown, with a progress bar comparing the table **rows** against the total row count.
- **Other tables** — internal SQLite tables are grouped into a single aggregated block with their count, rows and size.

## Default data

The **Default data** subtab lets you restore the records the application inserts by default. You can restore a single record, all records from a source, or all of them at once.

::warning
Restoring overwrites changes made to those default records. The action does not affect the rest of the database data.
::
