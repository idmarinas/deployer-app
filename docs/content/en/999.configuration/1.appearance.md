The application appearance (theme and language) can be changed from the application menu and from the **Appearance** card in settings.

## Light / dark theme

You can switch between **light** and **dark** from the **application menu** or from the **Appearance** card in settings.

The preference is stored in the database (`theme_color` setting), so it is kept on every startup.

## Language

The interface is translated into several languages (Spanish, English...). You can change it from the **application menu** or from the **Appearance** card in settings.

The language preference is stored in the database (`locale` setting) and is applied **without restarting**.

Languages are loaded **on demand** (lazy loading): only the translation bundle for the active language is downloaded.

## Reset window

From the **application menu**, the **Reset window** action restores the default window size (**1400×900**) and centers it on screen. Useful when the window has been resized or moved out of view.

## Persistence

Both settings are stored in the `settings` table of your local database:

| Setting | Values | Description |
| --- | --- | --- |
| `theme_color` | `light` / `dark` | Interface theme |
| `locale` | language code | Interface language |
