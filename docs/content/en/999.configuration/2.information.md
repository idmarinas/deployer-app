The **Information** settings tab shows the data for the current :vars{n="project"} installation.

## Displayed data

- **Name** — the application name.
- **Version** — installed version (e.g. `0.1.1`).
- **Identifier** — the Tauri application (bundle) identifier.
- **Copyright** — copyright notice.
- **Publisher** — publishing entity (on Windows, the signer).

## Environment

It also shows the **versions of the technologies** the application is built on:

- **Tauri**
- **Vue**
- **Nuxt UI**

And the **platform** data:

- **Platform** — operating system (Windows, macOS, Linux).
- **Architecture** — machine architecture (x86_64, aarch64, etc.).

This data is useful when [reporting an issue](https://github.com/idmarinas/deployer-app/issues) or a vulnerability ([Security](/security)).
