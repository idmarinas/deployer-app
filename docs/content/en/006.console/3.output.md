The remote console terminal shows output with an almost black background and light green text, in a monospace font.

## Streaming output

Standard output and error output are interleaved **in the order the host produces them** and appear in real time. This lets you follow the progress of long-running commands (deployments, logs, builds) without waiting for them to finish.

While the execution is in progress, the header shows **Running…**. Connection, timeout or cancellation errors are appended to the terminal text and **do not produce an exit code**.

## Exit code

The exit-code badge only appears once the execution has finished and a code has been received:

- **`0`** — the command finished successfully (green badge).
- **Non-zero** — the command finished with an error (red badge); the value is decided by the remote process.

## Tips

- **Clear** removes the output, the error and the exit code; it is only available when there is output in the terminal.
- **Cancel** interrupts the job and closes the SSH session, but does not send a signal to the remote process: it may keep running and no exit code is shown.
- Ad-hoc executions use the same component as the [command test dialog](/commands/testing), although there the full result is shown at the end, without streaming.
