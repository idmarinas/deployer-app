The **remote console** lets you run SSH commands on any of your hosts and watch the output **stream live**, without leaving the app.

## Select the host

The selector at the top only offers **enabled hosts** (see [Managing hosts](/hosts/manage)). If none is selected, the console warns you and the execution controls stay disabled.

## Run a command

When you run it, line breaks in the command are normalized and, if you have set a working directory, it is applied as `cd '<directory>' && <command>`, with the directory quoted with single quotes and escaped. The default directory is `/`; if you clear the field, the command is sent without the `cd` prefix.

The **timeout** can be left empty: in that case **300 seconds** are applied. Output arrives in real time and, when the command finishes, the terminal header shows the exit code. The **SSH retries** field starts at **3** and limits reconnection attempts if the session drops; the backend also applies 3 when it receives `null`.

::note
The timeout is a single deadline for the whole command: time spent producing output counts toward it and does not extend it.
::

## Variables in the console

The console accepts `{{global.slug}}` references in the **command** and the **working directory**, and resolves them when you run it ([Variable interpolation](/variables/interpolation)). If a reference cannot be resolved, the command is not sent and the reason appears in the terminal.

::warning
The console field is **plain text**: it offers no linter, autocomplete or interpolation preview, unlike the saved-command editor and the test dialog. Check the expression before running it.
::

Secret values are redacted from the output and the errors.

## Controlling execution

- **Cancel** cancels the current job (the one from the start event), not an arbitrary earlier job. It closes the SSH session, but does not send a signal to the remote process: it may keep running and no exit code is shown. Cascading cancellation to dependents and the **Skipped** status belong to the file manager, not to the console.
- **Clear** removes the output, the error and the exit code; the button only appears when there is output in the terminal.

::note
Running commands on a remote host is your responsibility: make sure you understand the impact of each command, especially if it requires privileges.
::
