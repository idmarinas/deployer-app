Welcome to **:vars{n="project"}**, a desktop application to deploy and manage your websites over **SSH/SFTP**.

## What is DeployerApp?

**:vars{n="project"}** is a ready-to-use desktop application built with **Tauri** and **Vue** that lets you manage all your servers from a single place, keeping the control of your data in a **local database**.

Instead of juggling between multiple terminals, scripts and tools, you get everything in one interface:

## Key Features

This application includes a variety of features designed to make deploying and managing your sites easier:

- **Cross-platform desktop** Built with **Tauri**, a lightweight and fast native application for Windows, macOS and Linux.
- **SSH/SFTP orchestration** Remote console with streaming output, file transfer and task cancellation in progress.
- **Host management** Connection tests, system metrics, updates and status of each SSH host.
- **Encrypted credentials** Sensitive fields are transparently encrypted with AES-256-GCM using versioned keys stored in the Stronghold vault and the system keychain.
- **Local database** SQLite managed with Drizzle ORM: your data never leaves your machine.
