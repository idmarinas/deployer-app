::note
:vars{n="project"} is a **desktop application**: you install it directly on your computer. The requirements on this page apply to your machine and to the servers you want to manage.
::

## Operating system

- **Windows** — Windows 10 or later.
- **macOS** — macOS 12 or later.
- **Linux** — Distributions with WebKitGTK support (Ubuntu, Fedora, Arch, etc.).

## Server access

- The hosts you want to manage must have **SSH** (port 22 by default) and **SFTP** enabled.
- You need valid credentials (username and password) or a **private key** to connect to each host.

::warning
Please make sure you meet these requirements before installing :vars{n="project"}.
::
