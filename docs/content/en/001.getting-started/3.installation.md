## Prerequisites

Before continuing, make sure you have installed:

- [Git](https://git-scm.com) to clone the repository.
- [Bun](https://bun.sh) as the package manager.
- **Rust** and the native **Tauri** dependencies for your operating system ([requirements guide](https://tauri.app/start/prerequisites/)): e.g. WebKit2GTK on Linux or the **Visual Studio Build Tools** on Windows.

## Run from source code

Clone the repository, install the dependencies and start the application in development mode:

```bash
git clone git@github.com:idmarinas/deployer-app.git
cd deployer-app
bun install
bun run tauri:dev
```

`bun run tauri:dev` compiles the Rust backend and opens the window with hot reload (Vite, port 1420).

## Build the installable binary

To generate the native installers for your platform:

```bash
bun run tauri build
```

The installers are generated in `src-tauri/target/release/bundle/`:

- **Windows** — `.msi` and `.exe` (NSIS).
- **macOS** — `.dmg` and `.app`.
- **Linux** — `.deb`, `.rpm` and `.AppImage`.
