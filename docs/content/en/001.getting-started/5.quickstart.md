Once :vars{n="project"} is installed, the minimal workflow to get everything running is:

::steps
  ### 1. Set up the database

  On **first launch** the app guides you to create or select the SQLite database where your data will be stored (see [Configuration](./4.configuration)).

  ### 2. Create a passkey

  Go to **Passkeys** and create your first SSH key. You can paste one or **generate a new one** by choosing the type (RSA, ED25519, ECDSA) and an optional passphrase. The private key is stored **encrypted** in your local database.

  ### 3. Add a server (host)

  Go to **Hosts** and create your first host: name, IP address, port, user and authentication method (password or passkey). If you choose a key, select the passkey you created in the previous step.

  ### 4. Test the connection

  From the list or the host view, press the **connection test** button to check that SSH access works correctly.

  ### 5. Explore the rest

  You can now use the **remote console** to run commands, check **system info**, **metrics** and **updates** for your hosts, or define **reusable commands** to automate tasks.
::

::note
All the rest of the management (create, edit and delete hosts and passkeys, console, etc.) is explained in detail in the [Passkeys](/passkeys), [Hosts](/hosts), [Commands](/commands) and [Remote console](/console) sections.
::
