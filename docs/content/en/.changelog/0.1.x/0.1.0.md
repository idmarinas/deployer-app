## Release highlights

- Initial configuration: app setup step guide with two buttons to select an existing SQLite database file or create a new one, running the migrations.
- Host management: full CRUD with SSH connection test, system/metrics check, and package updates.
- Passkey management: CRUD with SSH key generation (RSA, ED25519, ECDSA), fingerprint derivation, and export to servers.
- Remote console: SSH command execution with real-time streaming, file upload/download, and cancellation.
- AES-GCM encryption with a Stronghold vault for sensitive fields (passwords, key_content, passphrase).

## Security

- Transparent AES-GCM encryption for fields declared as `encryptedText(...)` in the Drizzle schema, covering `hosts.password`, `passkeys.key_content`, and `passkeys.passphrase`. ([`c5ea7f3`](https://github.com/idmarinas/deployer-app/commit/c5ea7f3)) ([@idmarinas](https://github.com/idmarinas))
- Stronghold vault with versioned keys per scope (`encrypt:{table}.{column}:{version}`), key rotation, and data re-encryption from the security tab. ([@idmarinas](https://github.com/idmarinas))
- Encryption and decryption are performed in the frontend, the only writer of the Stronghold vault; the backend only reads keys in read-only mode (`StrongholdVault::open`) to decrypt SSH credentials. ([`9f68631`](https://github.com/idmarinas/deployer-app/commit/9f68631)) ([@idmarinas](https://github.com/idmarinas))
- All encrypted values masked with `BLANK_VALUE` in proxy responses so the frontend never receives raw encrypted data. ([`91a349c`](https://github.com/idmarinas/deployer-app/commit/91a349c)) ([@idmarinas](https://github.com/idmarinas))
