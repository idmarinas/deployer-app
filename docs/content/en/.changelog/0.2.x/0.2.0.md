## Release highlights

- **Reusable commands**: new module to create, edit, enable, disable, test and delete SSH commands stored in the database, with configurable output parser and timeout.
- **Code editor**: commands are written in a CodeMirror-based editor with Bash syntax highlighting, line numbers and tools to wrap the script in `heredoc` or `bash -c`.
- **Command-driven hosts**: system information, metrics and package updates are obtained through internal database commands, with a cooldown countdown and persistence of the results.
- **Documentation**: new bilingual site (Spanish and English) with guides by module, release history and automatic deployment to GitHub Pages.

## Changed

- The host view obtains system information, metrics and updates through the internal database commands. The Rust commands `host_check_system_info`, `host_check_metrics` and `host_check_updates` were removed; applying updates still uses `host_update_packages`. ([`5190cc0`](https://github.com/idmarinas/deployer-app/commit/5190cc0)) ([`b818887`](https://github.com/idmarinas/deployer-app/commit/b818887)) ([@idmarinas](https://github.com/idmarinas))
- The info, metrics and updates buttons show a **countdown** and remain disabled until their cooldown expires. Results are stored in the database and the hosts cache is invalidated after each query. ([`5190cc0`](https://github.com/idmarinas/deployer-app/commit/5190cc0)) ([`06479df`](https://github.com/idmarinas/deployer-app/commit/06479df)) ([@idmarinas](https://github.com/idmarinas))
- Total host memory and total disk are displayed in human-readable format (B, KB, MB, GB...) instead of the byte value. ([`06479df`](https://github.com/idmarinas/deployer-app/commit/06479df)) ([@idmarinas](https://github.com/idmarinas))
- The initial setup and migration flow includes a **seed** step that inserts or updates the internal commands without duplicating them; when creating a new database it also saves the language and theme settings. ([`f10797c`](https://github.com/idmarinas/deployer-app/commit/f10797c)) ([`49cd96a`](https://github.com/idmarinas/deployer-app/commit/49cd96a)) ([@idmarinas](https://github.com/idmarinas))
- The remote console was reorganized into reusable components for the command, output and file transfer views, keeping streaming, cancellation and the exit code. ([`3a1eecd`](https://github.com/idmarinas/deployer-app/commit/3a1eecd)) ([@idmarinas](https://github.com/idmarinas))
- Expanded cards in the list use `ItemCard` in the commands module as well, with the full script, the parser and the creation and update dates. ([`4d3c8ca`](https://github.com/idmarinas/deployer-app/commit/4d3c8ca)) ([@idmarinas](https://github.com/idmarinas))

## Fixed

- Fixed the SSH console exit code: if the channel received `EOF` before the exit status, it now waits for the channel to close to capture the real `exit_status`. ([`a2e0937`](https://github.com/idmarinas/deployer-app/commit/a2e0937)) ([@idmarinas](https://github.com/idmarinas))
- `CRLF` and `CR` line breaks are normalized to `LF` before running a remote command, preventing scripts from storing carriage returns that bash interprets as part of the command. ([`fcd3318`](https://github.com/idmarinas/deployer-app/commit/fcd3318)) ([@idmarinas](https://github.com/idmarinas))
- Fixed the CPU, RAM and disk usage output format of the internal commands so the percentages are interpreted correctly in the host view. ([`3a86a48`](https://github.com/idmarinas/deployer-app/commit/3a86a48)) ([@idmarinas](https://github.com/idmarinas))
- The seed command scripts use `String.raw` to preserve the Bash escapes (`\"`, `\$`, `\\`, `\n`...), preventing the command stored in SQLite from being broken on the server. ([`c651815`](https://github.com/idmarinas/deployer-app/commit/c651815)) ([`433da28`](https://github.com/idmarinas/deployer-app/commit/433da28)) ([@idmarinas](https://github.com/idmarinas))

- `ItemCard` supports numeric and text identifiers, needed for command keys, and the alignment of the badges in the right slot was adjusted. ([`207c84b`](https://github.com/idmarinas/deployer-app/commit/207c84b)) ([`3b485c0`](https://github.com/idmarinas/deployer-app/commit/3b485c0)) ([@idmarinas](https://github.com/idmarinas))
