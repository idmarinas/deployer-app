## Release highlights

- **Command input parameters**: a command can declare values that are requested before it runs, substituted in the script with `{{params.<key>}}` and never stored.
- **Host fingerprint**: SSH and SFTP connections check the server key and require confirming its fingerprint —`SHA256:<base64>`— when it is new or has changed.
- **Remote console**: every run has a job identifier, can be cancelled selectively and reports its status and exit code in the terminal.
- **Remote file manager (experimental)**: two panels, one for the local computer and one for the remote server, with level-by-level navigation, remembered selection and a transfer queue that survives closing the app.
- **Base directory per server**: each host defines the initial path of the remote panel, with an action to reset it that does not affect the console's working directory.
- **Package updates**: the Updates tab no longer relies on backend-specific logic and uses an editable seed command.

## Changed

- Command execution builds the `params` scope, applies defaults for missing keys and fills in declared keys without a value so interpolation does not fail. ([`9321c56`](https://github.com/idmarinas/deployer-app/commit/9321c56))
- The command test dialog loads the global scope before resolving defaults and does not recalculate them while it stays open. ([`9321c56`](https://github.com/idmarinas/deployer-app/commit/9321c56))
- The remote console timeout is a single deadline for the whole run: receiving output no longer restarts the counter, and output is grouped into chunks before being sent to the interface. ([`b2c1da7`](https://github.com/idmarinas/deployer-app/commit/b2c1da7))
- The sidebar regroups its items: servers and passkeys move to the first group, commands and variables to the second, and console, file manager and trash sit in the footer, with the trash in red. - The **Updates** tab applies packages with the **Update packages** seed command and stops using the backend-specific command. ## Security

- SSH and SFTP connections verify the server key fingerprint and block the connection when it is unknown or does not match the stored one, until it is confirmed from the host form. ([`6c440ea`](https://github.com/idmarinas/deployer-app/commit/6c440ea))
- Values entered for parameters are not persisted, and secret global variables remain masked in the command preview. ([`9321c56`](https://github.com/idmarinas/deployer-app/commit/9321c56))
