## Release highlights

- **Global variables**: new module to create variables with a name, slug, description, enabled state and value, with secret values encrypted in the Stronghold vault and masked in the interface.
- **Variable interpolation**: `{{global.slug}}` references are resolved when running commands and working directories, with editor autocompletion, an interpolated preview, position-aware errors and redaction of secret values in outputs and messages.
- **Trash**: soft delete for hosts, commands, passkeys and variables with Active, Inactive and Deleted tabs, **Undo**, restore, individual purge and empty trash, with warnings when an item is referenced or in use.
- **Code editor**: CodeMirror extensions are extracted into reusable modules, with HTML, JavaScript, PHP, variable autocompletion, interpolation highlighting and Bash script formatting added.
- **Queries and settings**: a CRUD query factory unifies soft delete, references and notifications; settings gain default data restoration and more database information.

## Security

- Values of variables marked as secret are encrypted with AES-GCM and a versioned key in the Stronghold vault, and are masked on reads so they are never shown in the interface. ([`294c9bc`](https://github.com/idmarinas/deployer-app/commit/294c9bc)) ([`00ca24a`](https://github.com/idmarinas/deployer-app/commit/00ca24a))
- Secrets are decrypted only when resolving an interpolation, are never cached, and are replaced with a marker in previews, errors and command output. ([`de590ee`](https://github.com/idmarinas/deployer-app/commit/de590ee))
- Deleted variables no longer resolve in interpolation and disabled ones are distinguished from missing ones, preventing a command from using a withdrawn value or silently interpreting an invalid reference. ([`09c181c`](https://github.com/idmarinas/deployer-app/commit/09c181c))
