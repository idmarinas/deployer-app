El **test de conexión** verifica que el host responde por SSH con las credenciales configuradas.

## Dónde se ejecuta

- Desde el **listado de servidores**, en la columna de acciones de cada fila.
- Desde la **vista de detalle** del host.
- Justo después de **guardar el alta**, para obtener la huella del servidor.
- Desde **Comprobar**, en el campo **Huella del servidor** del formulario de edición.

## Cómo funciona

Al pulsar el botón, la aplicación intenta establecer una sesión SSH con los datos guardados. El resultado se muestra con una notificación:

- **Cargando** — el test está en curso.
- **Éxito** — la conexión se estableció correctamente.
- **Error** — con el motivo (credenciales incorrectas, host inalcanzable, puerto cerrado, clave del servidor cambiada, etc.).

## Notas

- El test **no aplica tiempo de espera**: tras una comprobación, puedes volver a probar cuando quieras. Solo mientras un test está en curso el botón permanece en estado de carga.
- Funciona también con **hosts deshabilitados**: comprobar la conexión no está restringido por el conmutador *habilitado*.
- El establecimiento de la sesión se corta a los **15 segundos** (timeout de `client::connect`), momento en el que se notifica el error. Una vez conectada, la ejecución remota dispone de **300 segundos**.

## Huella del servidor

El test también verifica la **huella SSH** guardada en el host (`SHA256:<base64>`):

- Si el host aún no tiene huella, la conexión se rechaza y se muestra la huella vista para que la confirmes desde el formulario.
- Si la clave del servidor cambia, la conexión se rechaza con un aviso de discrepancia; confirma la nueva huella desde la edición del host solo si el cambio es legítimo.

::note
El test de conexión usa las credenciales actuales del host: si acabas de cambiar la contraseña o la clave, el resultado refleja esa configuración.
::
