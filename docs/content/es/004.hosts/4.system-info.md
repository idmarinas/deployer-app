La pestaña **Información del servidor** de la vista de un host te permite consultar los detalles del sistema operativo remoto.

## Qué muestra

- **Distribución / SO** — sistema operativo y versión.
- **Kernel** — versión del kernel.
- **Arquitectura** — plataforma del equipo (x86_64, aarch64, etc.).
- **Gestor de paquetes** — apt, yum o dnf.
- **CPU** — número de núcleos.
- **Memoria total** — RAM instalada.
- **Disco total** — capacidad de almacenamiento.

## Cómo se comprueba

Desde esa pestaña, pulsa **Actualizar**. La aplicación ejecuta por SSH el comando guardado en la base de datos: el frontend orquesta la interpolación y el backend ejecuta la orden remota, y guarda el resultado asociado al host. Mientras no lo compruebes, la pestaña no tendrá datos.

## Tiempo entre comprobaciones

El botón se rehabilita al **minuto** de cada comprobación. Una vez comprobada, la información queda guardada en el host hasta que se vuelva a actualizar; no hay una espera en el backend.

::note
La info del sistema se obtiene con el comando semilla `system_info` de :vars{n="project"}. Consulta [Comandos → Comandos internos](/commands/built-in) para más detalles.
::
