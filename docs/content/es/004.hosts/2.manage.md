El módulo **Servidores** (menú `/dashboard/hosts`) permite administrar todos tus hosts.

## Listado

La tabla de servidores muestra: número, nombre, IP, puerto, tipo de autenticación, si está habilitado y sus acciones (ver, editar, eliminar, **Probar conexión**). Cada fila se puede expandir para ver más detalles.

## Crear un servidor

Desde el botón **Añadir**, define el **nombre** (y la descripción opcional), el **host** (IPv4 o IPv6), el **puerto** (0-65535; 22 por defecto) y el **usuario**. Elige el **tipo de autenticación**: **Contraseña** (campo obligatorio) o **Clave de acceso** (selecciona una passkey). Guarda.

El campo **Directorio base (gestor de archivos)** fija la ruta inicial del panel remoto. Acepta rutas absolutas con `/`, `C:\...` o UNC; si se deja vacío, se usa la raíz `/`.

::note
Este directorio base no es el directorio de trabajo de la consola remota ni de los comandos de despliegue: solo decide dónde empieza la exploración en el [gestor de archivos](/file-manager/navigation). Puedes cambiar de directorio durante la navegación y «Restablecer ruta» vuelve a este valor.
::

El formulario **valida la unicidad** del nombre de forma asíncrona contra la base de datos; la comprobación no filtra `deleted_at`, así que un nombre en la papelera sigue considerado ocupado.

Al guardar, la aplicación comprueba la conexión justo después de crear el host y muestra la **huella SSH** del servidor para que la confirmes. Esa huella queda asociada al host y se verificará en cada conexión; también puedes obtenerla y confirmarla desde el formulario de edición.

## Ver

La vista de detalle muestra los datos básicos (nombre, IP, puerto, usuario, autenticación, directorio base y huella SSH) junto al estado de habilitado. El resto de la información se organiza en las pestañas de [Info del sistema](./system-info), [Actualizaciones](./updates) y [Métricas](./metrics).

## Editar

El formulario de edición es el mismo que el de creación, precargado. Puedes cambiar cualquier dato, incluido el método de autenticación y el directorio base del gestor de archivos. Si cambias de contraseña a clave (o viceversa), el campo que ya no aplica se limpia automáticamente. El campo **Huella del servidor** es de solo lectura: usa **Comprobar** para obtenerla (si aún no existe) o para reconfirmar una huella nueva tras un cambio legítimo de clave del servidor.

## Habilitar / deshabilitar

El conmutador **habilitado** activa o desactiva el host. Los hosts deshabilitados no se muestran en los selectores de servidor de la **consola**, del **diálogo de test de comandos** ni del **gestor de archivos**. Sus listados guardados se descartan y las transferencias interrumpidas no se pueden reintentar mientras el host siga deshabilitado.
