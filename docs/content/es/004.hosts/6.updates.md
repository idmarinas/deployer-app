La pestaña **Actualizaciones** de la vista de un host te permite buscar paquetes actualizables y aplicar las actualizaciones directamente desde la aplicación.

## Buscar actualizaciones

Desde esa pestaña, pulsa **Actualizar** para buscar. La aplicación ejecuta por SSH el comando semilla `upgradable_packages` —el frontend orquesta la interpolación y el backend ejecuta la orden remota— y guarda la lista de paquetes disponibles.

Cada paquete se **clasifica automáticamente** según el tipo de cambio:

- **Parche** (`patch`) — corrección de errores.
- **Menor** (`minor`) — nueva funcionalidad compatible.
- **Mayor** (`major`) — cambio mayor (puede romper compatibilidad).
- **Empaquetado** (`packaging`) — cambio propio del empaquetado, sin una versión semver comparable.
- **Desconocido** (`unknown`) — no se puede determinar el tipo.

Además, cada paquete lleva un indicador **Seguridad** (`is_security`) independiente de la clasificación.

## Aplicar actualizaciones

Desde la tabla de paquetes puedes:

- **Actualizar** — botón en la fila del paquete.
- **Actualizar seleccionados ({count})** — marca varios paquetes y pulsa el botón.
- **Actualizar todo ({count})** — aplica todas las actualizaciones disponibles.

Las tres acciones muestran un diálogo de confirmación antes de ejecutarse.

La actualización usa el comando semilla `update_packages`, editable desde la biblioteca de comandos, con el script `sudo DEBIAN_FRONTEND=noninteractive apt-get install --only-upgrade -y {{params.packages}}`. El parámetro `packages` es obligatorio y contiene los paquetes elegidos. El usuario remoto necesita `sudo` sin contraseña, porque la sesión SSH no es interactiva: en 0.4.0 se retiró la opción **Usar sudo**, así que el comando siempre emplea `sudo`. La vista no ejecuta `apt-get update`: la caché de índices debe estar al día. Solo es aplicable en servidores con `apt-get`.

## Tiempo entre comprobaciones

El botón **Actualizar** se rehabilita **2 minutos** después de cada búsqueda. No existe una opción para forzarla antes; al pulsarlo de nuevo una vez transcurrido ese plazo se lanza una nueva comprobación.

::note
La detección y clasificación usa el gestor de paquetes del servidor ([Info del sistema](./system-info)) y el comando semilla `upgradable_packages`.
::
