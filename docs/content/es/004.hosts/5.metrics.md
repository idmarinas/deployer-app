La pestaña **Estado del servidor** (métricas) de la vista de un host muestra una instantánea del uso de recursos del servidor.

## Qué muestra

- **Uso de CPU** — porcentaje de uso de la CPU.
- **Uso de RAM** — porcentaje de memoria en uso.
- **Uso del disco** — porcentaje de disco ocupado.

## Cómo se comprueban

Desde esa pestaña, pulsa **Actualizar**. La aplicación ejecuta por SSH el comando guardado en la base de datos —el frontend orquesta la interpolación y el backend ejecuta la orden remota— y guarda los porcentajes asociados al host.

## Tiempo entre comprobaciones

El botón se rehabilita **1 minuto** después de cada comprobación. Al expirar ese plazo, una nueva pulsación vuelve a ejecutar el comando por SSH; no hay una espera de 15 minutos en el backend.

::note
Las métricas se obtienen con el comando semilla `system_metrics` de :vars{n="project"}. Consulta [Comandos → Comandos internos](/commands/built-in) para más detalles.
::
