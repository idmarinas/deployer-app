Una vez instalada :vars{n="project"}, el flujo mínimo para tener todo funcionando es:

::steps
### 1. Configura la base de datos

En el **primer arranque** la aplicación te guía para crear o seleccionar la base de datos SQLite donde se guardarán tus datos (consulta [Configuración](./4.configuration)).

### 2. Crea una clave de acceso (passkey)

Ve a **Claves de acceso** y crea tu primera clave SSH. Puedes pegarla o **generar una nueva** eligiendo el tipo (RSA, ED25519, ECDSA) y una passphrase opcional. La clave privada se almacena **cifrada** en tu base de datos local.

### 3. Añade un servidor (host)

Ve a **Servidores** y crea tu primer host: nombre, dirección IP, puerto, usuario y método de autenticación (contraseña o clave de acceso). Si eliges clave, selecciona la passkey que creaste en el paso anterior.

### 4. Prueba la conexión

Desde el listado o la vista del host, pulsa el botón de **test de conexión** para comprobar que el acceso SSH funciona correctamente.

### 5. Explora el resto

Ya puedes usar la **consola remota** para ejecutar comandos, consultar **info del sistema**, **métricas** y **actualizaciones** de tus hosts, o definir **comandos reutilizables** para automatizar tareas.
::

::note
Toda la gestión posterior (crear, editar, eliminar hosts y passkeys, consola, etc.) se explica en detalle en las secciones [Claves de acceso](/passkeys), [Servidores](/hosts), [Comandos](/commands) y [Consola remota](/console).
::
