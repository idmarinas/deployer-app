## Requisitos previos

Antes de continuar, asegúrate de tener instalado:

- [Git](https://git-scm.com) para clonar el repositorio.
- [Bun](https://bun.sh) como gestor de paquetes.
- **Rust** — compilador y dependencias nativas de **Tauri** según tu sistema operativo ([guía de requisitos](https://tauri.app/start/prerequisites/)): p. ej. WebKit2GTK en Linux o las **Build Tools de Visual Studio** en Windows.

## Ejecutar desde el código fuente

Clona el repositorio, instala las dependencias y arranca la aplicación en modo desarrollo:

```bash [Terminal]
git clone git@github.com:idmarinas/deployer-app.git
cd deployer-app
bun install
bun run tauri:dev
```

`bun run tauri:dev` compila el backend de Rust y abre la ventana con recarga en caliente (Vite, puerto 1420).

## Construir el binario instalable

Para generar los instaladores nativos de tu plataforma:

```bash [Terminal]
bun run tauri build
```

Los instaladores se generan en `src-tauri/target/release/bundle/`:

- **Windows** — `.msi` y `.exe` (NSIS).
- **macOS** — `.dmg` y `.app`.
- **Linux** — `.deb`, `.rpm` y `.AppImage`.
