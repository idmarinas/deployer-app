::note
:vars{n="project"} no requiere ninguna configuración previa para funcionar. La única configuración inicial es la **base de datos**: en el primer arranque puedes **seleccionar una base de datos existente** o **crear una nueva**, y a partir de ahí solo tienes que añadir tus datos (hosts, passkeys, etc.).
::
