Bienvenido a **:vars{n="project"}**, una aplicación de escritorio para desplegar y administrar tus sitios web mediante **SSH/SFTP**.

## Qué es :vars{n="project"}

**:vars{n="project"}** es una aplicación de escritorio lista para usar, construida con **Tauri** y **Vue**, que te permite gestionar todos tus servidores desde un solo lugar, manteniendo el control de tus datos en una **base de datos local**.

En lugar de alternar entre múltiples terminales, scripts y herramientas, lo tienes todo en una única interfaz. Esta guía está organizada por módulos:

- **Claves de acceso** — claves privadas SSH reutilizables ([ver general](/passkeys/overview)).
- **Servidores** — equipos SSH con estado, métricas, actualizaciones y consola ([ver general](/hosts/overview), [Consola remota](/console/usage)).
- **Comandos** — tareas SSH reutilizables que se prueban y ejecutan contra cualquier host ([ver general](/commands/overview)).
- **Configuración de la app** — tema, idioma, base de datos y seguridad ([ver general](/configuration/appearance)).

## Privacidad

Todos tus datos —hosts, claves y ajustes— se guardan en una **base de datos local** en tu equipo. Las credenciales (contraseñas y claves privadas) se cifran de forma transparente con **AES-256-GCM** mediante claves versionadas en el vault Stronghold y el keychain del sistema: nada sale de tu máquina ([Seguridad](/security), [Vault](/app/vault)).
