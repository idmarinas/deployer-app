Bienvenido a **:vars{n="project"}**, una aplicación de escritorio para desplegar y administrar tus sitios web mediante **SSH/SFTP**.

## ¿Qué es DeployerApp?

**:vars{n="project"}** es una aplicación de escritorio lista para usar, construida con **Tauri** y **Vue**, que te permite gestionar todos tus servidores desde un solo lugar, manteniendo el control de tus datos en una **base de datos local**.

En lugar de alternar entre múltiples terminales, scripts y herramientas, lo tienes todo en una única interfaz:

## Características principales

Esta aplicación incluye una variedad de funciones diseñadas para facilitar el despliegue y la gestión de tus sitios:

- **Escritorio multiplataforma** Construida con **Tauri**, una aplicación nativa ligera y rápida para Windows, macOS y Linux.
- **Orquestación SSH/SFTP** Consola remota con salida en streaming, transferencia de archivos y cancelación de tareas en curso.
- **Gestión de hosts** Test de conexión, métricas del sistema, actualizaciones y estado de cada host SSH.
- **Credenciales cifradas** Los campos sensibles se cifran de forma transparente con AES-256-GCM usando claves versionadas almacenadas en el vault Stronghold y el keychain del sistema.
- **Base de datos local** SQLite gestionado con Drizzle ORM: tus datos nunca salen de tu equipo.
