Puedes copiar la **clave pública** de una passkey a un servidor para poder conectarte con esa clave sin contraseña. La aplicación se encarga de añadirla al archivo `~/.ssh/authorized_keys` del usuario remoto.

## Cómo funciona

Desde el **listado** de claves, usa la acción de copiar al servidor: es un botón de solo icono, sin texto ni tooltip; la vista de detalle no ofrece esta acción. Se abre un diálogo donde debes indicar:

1. **Servidor** — el host donde quieres copiar la clave. El selector tiene buscador, muestra el estado de cada host y excluye los hosts borrados. El interruptor **Solo servidores habilitados** filtra los deshabilitados y está desactivado por defecto; al cambiarlo, la selección se limpia si el host ya no está disponible.
2. Los botones del pie del diálogo:
   - **Copiar al servidor** — añade la clave pública a las autorizadas del servidor.
   - **Eliminar del servidor** — quita esa clave pública si ya estaba instalada.

La aplicación se conecta por SSH y ejecuta los comandos necesarios sobre `~/.ssh/authorized_keys`: crea `~/.ssh` con permisos `700`, crea el archivo con `600` y añade la línea de la clave. Para eliminarla, reescribe el archivo vía `.tmp` con `chmod 600`. La clave se compara por **línea exacta**, sin comentarios, y la operación se ejecuta como el usuario configurado en el host.

## Requisitos

- El host debe tener **credenciales válidas guardadas** (contraseña o la passkey referenciada por el host), porque la aplicación necesita conectarse por SSH: no usa automáticamente la passkey que estás copiando. El diálogo no ofrece campos para credenciales temporales.
- Un host **deshabilitado sí se puede seleccionar** con el filtro por defecto; solo se excluyen los hosts borrados.
- :labels-version{version="0.4" is-new size="sm"} El servidor debe tener una **huella SSH confirmada** (`SHA256:<base64>`) y no haber cambiado: si falta o no coincide, la copia o eliminación se bloquea.

## Notas

- **Copiar es idempotente**: la comprobación `grep -qxF` evita duplicar una línea exactamente igual. No se normalizan comentarios ni espacios previos, así que una variante de la misma clave se añadiría como otra línea.
- **Eliminar del servidor** quita **todas** las líneas exactamente iguales y devuelve un error si el archivo `authorized_keys` no existe o si esa clave pública no estaba instalada.
