## Destacados de la versión

- **Comandos reutilizables**: nuevo módulo para crear, editar, activar, desactivar, probar y eliminar comandos SSH almacenados en la base de datos, con parser de salida y timeout configurables.
- **Editor de código**: los comandos se escriben en un editor basado en CodeMirror con resaltado de sintaxis Bash, numeración de líneas y herramientas para envolver el script en `heredoc` o `bash -c`.
- **Hosts basados en comandos**: la información del sistema, las métricas y las actualizaciones de paquetes se obtienen con comandos internos de la base de datos, con cuenta atrás de cooldown y persistencia de los resultados.
- **Documentación**: nuevo sitio bilingüe (español e inglés) con guías por módulos, historial de versiones y despliegue automático en GitHub Pages.

## Cambiado

- La vista de un host obtiene la información del sistema, las métricas y las actualizaciones mediante los comandos internos de la base de datos. Se eliminaron los comandos Rust `host_check_system_info`, `host_check_metrics` y `host_check_updates`; la aplicación de actualizaciones sigue usando `host_update_packages`. ([`5190cc0`](https://github.com/idmarinas/deployer-app/commit/5190cc0)) ([`b818887`](https://github.com/idmarinas/deployer-app/commit/b818887)) ([@idmarinas](https://github.com/idmarinas))
- Los botones de actualización de info, métricas y actualizaciones muestran una **cuenta atrás** y permanecen deshabilitados hasta que expira su cooldown. Los resultados se guardan en la base de datos y se invalida la caché de hosts tras cada consulta. ([`5190cc0`](https://github.com/idmarinas/deployer-app/commit/5190cc0)) ([`06479df`](https://github.com/idmarinas/deployer-app/commit/06479df)) ([@idmarinas](https://github.com/idmarinas))
- La memoria total y el disco total del host se muestran en formato legible (B, KB, MB, GB...) en lugar del valor en bytes. ([`06479df`](https://github.com/idmarinas/deployer-app/commit/06479df)) ([@idmarinas](https://github.com/idmarinas))
- El flujo de configuración inicial y de migraciones incorpora un paso de **seed** que inserta o actualiza los comandos internos sin duplicarlos; al crear una base de datos nueva también guarda los ajustes de idioma y tema. ([`f10797c`](https://github.com/idmarinas/deployer-app/commit/f10797c)) ([`49cd96a`](https://github.com/idmarinas/deployer-app/commit/49cd96a)) ([@idmarinas](https://github.com/idmarinas))
- La consola remota se reorganizó en componentes reutilizables para el comando, la salida y las vistas de transferencia de archivos, manteniendo el streaming, la cancelación y el código de salida. ([`3a1eecd`](https://github.com/idmarinas/deployer-app/commit/3a1eecd)) ([@idmarinas](https://github.com/idmarinas))
- Las tarjetas expandidas del listado usan `ItemCard` también en el módulo de comandos, con el script completo, el parser y las fechas de creación y actualización. ([`4d3c8ca`](https://github.com/idmarinas/deployer-app/commit/4d3c8ca)) ([@idmarinas](https://github.com/idmarinas))

## Correcciones

- Se corrigió el código de salida de la consola SSH: si el canal recibía `EOF` antes del estado de salida, ahora se espera al cierre del canal para capturar el `exit_status` real. ([`a2e0937`](https://github.com/idmarinas/deployer-app/commit/a2e0937)) ([@idmarinas](https://github.com/idmarinas))
- Se normalizan los saltos de línea `CRLF` y `CR` a `LF` antes de ejecutar un comando remoto, evitando que los scripts guarden retornos de carro que bash interpreta como parte del comando. ([`fcd3318`](https://github.com/idmarinas/deployer-app/commit/fcd3318)) ([@idmarinas](https://github.com/idmarinas))
- Se corrigió el formato de salida de uso de CPU, RAM y disco de los comandos internos para que los porcentajes se interpreten correctamente en la vista del host. ([`3a86a48`](https://github.com/idmarinas/deployer-app/commit/3a86a48)) ([@idmarinas](https://github.com/idmarinas))
- Los scripts de los comandos de semilla usan `String.raw` para conservar los escapes de Bash (`\"`, `\$`, `\\`, `\n`...), evitando que el comando guardado en SQLite quede roto en el servidor. ([`c651815`](https://github.com/idmarinas/deployer-app/commit/c651815)) ([`433da28`](https://github.com/idmarinas/deployer-app/commit/433da28)) ([@idmarinas](https://github.com/idmarinas))
- Se corrigió el nombre de la propiedad de personalización de comandos de `customized` a `custom`, alineándola con la columna de la tabla. ([`9e3562d`](https://github.com/idmarinas/deployer-app/commit/9e3562d)) ([@idmarinas](https://github.com/idmarinas))
- `ItemCard` admite identificadores numéricos y de texto, necesario para las claves de los comandos, y se ajustó la alineación de las insignias del slot derecho. ([`207c84b`](https://github.com/idmarinas/deployer-app/commit/207c84b)) ([`3b485c0`](https://github.com/idmarinas/deployer-app/commit/3b485c0)) ([@idmarinas](https://github.com/idmarinas))
- El slug de un comando deja de regenerarse al cambiar el nombre si el usuario ya lo había personalizado. ([`e95e153`](https://github.com/idmarinas/deployer-app/commit/e95e153)) ([@idmarinas](https://github.com/idmarinas))
