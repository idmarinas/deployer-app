La terminal de la consola remota muestra la salida con fondo casi negro y texto verde claro, en fuente monoespaciada.

## Salida en streaming

La salida estándar y la de errores se mezclan **en el orden en que el servidor las produce** y aparecen en tiempo real. Así puedes seguir el progreso de comandos largos (despliegues, logs, compilaciones) sin esperar a que terminen.

Mientras la ejecución está en curso, la cabecera muestra **Ejecutando…**. Los errores de conexión, timeout o cancelación se añaden al texto de la terminal y **no producen código de salida**.

## Código de salida (exit code)

La insignia del código aparece solo cuando la ejecución ha terminado y se ha recibido un código:

- **`0`** — el comando terminó correctamente (insignia verde).
- **Distinto de `0`** — el comando terminó con error (insignia roja); el valor lo decide el proceso remoto.

## Consejos

- **Limpiar** borra la salida, el error y el código de salida; solo está disponible cuando hay salida en la terminal.
- **Cancelar** interrumpe el job y cierra la sesión SSH, pero no envía una señal al proceso remoto: este puede seguir ejecutándose y no se muestra código de salida.
- La salida de las ejecuciones ad-hoc usa el mismo componente que el [diálogo de test de comandos](/commands/testing), aunque allí el resultado se muestra completo al terminar, sin streaming.
