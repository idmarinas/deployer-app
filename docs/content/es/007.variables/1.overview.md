Las **variables globales** son valores con un nombre legible y un **slug** único que se reutilizan en los comandos, en el directorio de trabajo de la consola y como valores por defecto de los [parámetros de entrada](/commands/inputs). Su uso se describe en [Interpolación](./interpolation).

## Qué guarda una variable

- **Slug** — clave estable usada en las expresiones. Se **autogenera** desde el nombre y queda **bloqueado** al editar; al crear la variable puedes desbloquearlo y personalizarlo.
- **Nombre y slug** — se comprueban por unicidad incluso cuando la fila está en la papelera.
- **Habilitada** — una variable deshabilitada no se resuelve, pero el linter la distingue de una inexistente.
- **Secreta** — el valor se cifra y no puede volverse público en esa fila.

Los demás campos del formulario —descripción enriquecida y valor— no cambian el comportamiento de la interpolación.

## Valor y secretos

El valor es obligatorio al crear la variable si está **habilitada** o marcada como **secreta**; una variable deshabilitada y no secreta puede quedarse como borrador con el valor vacío.

Las variables secretas se guardan **cifradas** con las claves del vault (`encryptedText(...)` sobre la columna `value`). En las lecturas normales el valor real no se muestra: la fila expandida del listado solo muestra un marcador enmascarado. El valor se descifra únicamente cuando el flujo lo necesita.

::warning
Una variable marcada como secreta **no puede volver a ser pública**. La opción de secreto se bloquea al editarla y la capa de datos fuerza `is_secret = true` si el registro ya era secreta.
::
