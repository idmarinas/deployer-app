Las **variables globales** son valores con un nombre legible y un **slug** único que se reutilizan en los comandos sin repetir el valor. Su uso se describe en [Interpolación](./interpolation).

## Qué guarda una variable

- **Nombre** — identificador legible y único.
- **Slug** — clave estable que identifica la variable en las expresiones. Se **autogenera** desde el nombre y queda **bloqueado** al editar.
- **Descripción** — texto enriquecido opcional.
- **Valor** — dato que se sustituirá al usar la variable.
- **Habilitada** — permite distinguir variables listas para usarse de borradores.
- **Secreta** — marca el valor como sensible.

## Valor y secretos

El valor es obligatorio cuando la variable está **habilitada** o marcada como **secreta**; una variable deshabilitada y no secreta puede quedarse como borrador con el valor vacío.

Las variables secretas se guardan **cifradas** con las claves del vault (`encryptedText(...)` sobre la columna `value`). En las lecturas normales el valor llega enmascarado, por lo que **no se muestra en el listado**; solo se descifra cuando el flujo lo necesita.

::warning
Una variable marcada como secreta **no puede volver a ser pública**. La opción de secreto se bloquea al editarla y la capa de datos fuerza `is_secret = true` si el registro ya era secreto.
::
