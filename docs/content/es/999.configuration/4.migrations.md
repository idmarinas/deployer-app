La pestaña **Migraciones** de la configuración lista las **migraciones aplicadas** en tu base de datos.

## Qué muestra

Cada migración incluye:

- **Versión** — identificador de la migración.
- **Descripción** — qué cambio introduce.
- **Fecha** — cuándo se aplicó.
- **Tiempo de ejecución** — cuánto tardó.
- **Estado** — **correcta** o **fallida**.

## Relación con el asistente de setup

Las migraciones se aplican automáticamente durante la [configuración inicial](/app/setup):

- Al **crear** una base de datos nueva.
- Al **seleccionar** una base de datos existente (se ejecutan las pendientes).
- Si faltan migraciones al arrancar, la app te redirige a `/deployer/migrations` para ejecutarlas antes de entrar en el dashboard.

## Gestión

Desde esta pestaña **solo se consulta** el historial: no se pueden ejecutar ni revertir migraciones aquí. La ejecución se hace siempre a través del flujo de configuración de la aplicación.
