El **cuadro de mandos** es la pantalla inicial del dashboard: ofrece un resumen del estado de tus datos y accesos directos a los módulos principales.

## Resumen

La tarjeta de **resumen** muestra cuántos **servidores** y **claves de acceso** están habilitados y deshabilitados.

## Últimos elementos

El panel lista los cinco servidores y las cinco claves de acceso más recientes que no se han eliminado, incluidos los deshabilitados. Desde cada lista puedes abrir el módulo completo ([Servidores](/hosts/overview), [Claves de acceso](/passkeys/overview)).

## Atajos de teclado

Desde el dashboard puedes abrir directamente los formularios de creación con el teclado:

| Atajo | Acción |
| --- | --- |
| `Shift+K` | Crear una nueva clave de acceso |
| `Shift+H` | Crear un nuevo servidor |
