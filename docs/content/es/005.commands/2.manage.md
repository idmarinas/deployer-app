El módulo **Comandos** permite administrar tus comandos reutilizables.

## Listado

La tabla muestra el botón para expandir, la **Clave** (con insignia **Interno** en los de semilla), el **Nombre**, el **Timeout** y el estado **Habilitado**. Al expandir una fila se ven la descripción, el comando completo, el tipo de parser y las fechas de creación y actualización. Puedes **Probar**, **Editar** y **Eliminar** cada comando; **Eliminar** está deshabilitado en los internos. La pestaña **Borrados** permite restaurar o purgar.

## Crear y editar

Desde **Añadir comando** defines el comando y puedes probarlo antes de guardarlo con **Probar**: esa prueba usa el texto aún no guardado. En edición, **Probar** ejecuta la definición guardada, aunque la vista previa refleje los cambios del formulario; guarda antes si modificaste el script o los parámetros ([Testing](./testing)). La clave se genera en el alta y no se puede cambiar después; los campos y sus reglas están en [Parámetros de entrada](./inputs) y [Parsers](./parsers).

## Habilitar / deshabilitar

El conmutador **habilitado** del toolbar activa o desactiva el comando. Los deshabilitados siguen en la pestaña **Inactivos**, pero no se pueden ejecutar: si pulsas **Probar** en uno de ellos, la ejecución falla con un error de comando deshabilitado.
